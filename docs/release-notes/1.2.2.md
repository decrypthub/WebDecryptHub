## WebDecryptHub 1.2.2

### 原生嵌入浏览器
- Windows（Win32）与 Linux X11 下，真实的 Chrome 窗口直接嵌在左侧面板中，点击、键盘输入直接作用于真实浏览器；Wayland 会话自动走 XWayland。
- 多会话标签切换、分栏拖动、最大化/还原时窗口跟随；弹出层（菜单、对话框）打开时自动让位。
- 修复：重启后偶发左侧一片黑屏（窗口管理器异步撤销管理与收养竞争），新增收养看门狗自动恢复；X11 下快速点击也能可靠获得键盘焦点。
- 设置 →「浏览器嵌入」：自动 / 原生嵌入 / 画面串流；嵌入失败时自动回落画面串流。

### 更清晰的画面串流
- 按屏幕 DPR 采集，JPEG 质量 90，静止时切换为无损 PNG；高分屏不再发虚（macOS 等不支持嵌入的平台使用此模式）。

### AI 上下文管理
- 上下文窗口随模型保存，快捷档位：自动（按模型推断）/ 128K / 256K / 300K / 500K / 1M / 自定义。
- 输入框旁的用量环：已用 / 上限 / 百分比，分类明细（系统提示、工具定义、摘要、对话、附件、工具结果）。
- 自动压缩（默认 85%，可选 80% / 90%）：先收起旧工具结果，仍超出再由模型生成结构化检查点（目标、约束、发现、脚本、请求、状态、下一步），最近对话原样保留。
- 手动压缩支持重点说明：在输入框输入 `/compact 关注 sign 算法`，或在用量弹层中填写。
- 聊天中显示压缩分隔线，可展开查看摘要；清空上下文 / 新对话（旧对话归档）。
- 附件：当前页面、脚本、请求（含请求/响应头）、工作区文件，以标签形式附在消息上。

### 可选内置 Chromium 内核
- 设置 →「浏览器内核」可选择系统 Chrome 或内置 Chromium（Chrome for Testing），一键下载，带进度条与 MD5 / SHA-256 校验，可删除或重新下载。

### 其它
- 删除内核、关闭会话、干净重试等确认框改为应用内对话框（Linux WebView 的原生确认框不阻塞，可能误执行）。
