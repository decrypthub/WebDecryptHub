## WebDecryptHub 1.3.0

### 工作区可以改一段、也能搜
- 新增 `workspace_edit`：按原文精确替换。默认必须唯一匹配，对不上或匹配多处会说明原因和附近内容；需要全部替换时用 `replace_all`。
- 新增 `workspace_grep`：在会话工作区里按正则搜索，可用目录和 glob 缩小范围。
- 原有的列出、读取、整文件写入、Node 运行和 npm 安装都还在。

### 工作区 Shell 与后台任务
- 新增 `workspace_shell`，工作目录固定在当前会话的 workspace。前台命令默认 30 秒超时，最长 2 分钟。
- `background` 可把进程留在后台，再用 `workspace_job_output` 看输出、`workspace_job_kill` 结束。后台任务最长约 10 分钟。
- 子进程环境会去掉 `WDH_LLM_API_KEY` 以及其他常见密钥变量。

### 安全 / 自主 / 计划
- 每个会话记住自己的模式，默认是**安全**。输入框旁可以切换，清单卡片上也会标出当前模式。
- **安全**：shell、npm install、覆盖 8KB 及以上的已有文件、重置会话、重启干净浏览器、跳到另一个网站，都会弹出应用内确认。可以对本会话始终允许某一类。模型自己填的 `confirm` 不会跳过这个确认。
- **自主**：不再弹出上述确认。
- **计划**：只能使用只读工具（请求、源码、搜索、工作区读取、任务清单）。点「执行计划」后回到进入计划之前的模式，并让 AI 按清单继续做。

### 逆向清单
- 对话顶部固定一张清单：定位参数、找到签名函数、抠代码 / 补环境、本地复现、与浏览器结果对比。AI 可以用 `todo_write` 更新，状态保存在会话里，压缩上下文时也会保留。

### 一键发给 AI
- 请求行右键，或请求详情里的按钮，可以把「分析此签名」或「复现此请求」挂成附件，并带上发起者。
- 脚本查看器里选中源码后，可以右键或点「发给 AI」。
- 「调用栈」会读取当前断点的调用栈和作用域，同样作为附件放进输入框。
