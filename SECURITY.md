# Security Policy

## Supported versions

The latest release tag (`v*`) on GitHub is the supported line for security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.
Email the DecryptHub maintainers via the contact channels listed on [ios.decrypthub.com](https://ios.decrypthub.com/), or use GitHub’s private vulnerability reporting if enabled on this repository.

Include: affected version, reproduction steps, impact, and any suggested fix.

## Scope notes

WebDecryptHub is a reverse-engineering **research** tool. Reports about third-party websites’ own protections are out of scope unless they demonstrate a vulnerability **in this application** (e.g. unsafe update install, path traversal, secret leakage).
